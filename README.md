## Overview

SPRL puts a coin's name in the hands of the wallets that hold it. When a sharper lookalike appears, holders vote, and the coin moves on without losing its mint, chart or crowd.

## Features

- Pinned contract-address bar with click-to-copy (locked until the address is announced)
- Live market board of busy Solana tokens, refreshed every 60 seconds while the tab is visible
- Row one of the board becomes SPRL as soon as its address is public
- Ticker ribbon driven by the same live data
- Motion-rich page that falls back to zero motion for reduced-motion users
